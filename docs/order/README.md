# Order Module (Модул за поръчки)

## Описание
Модулът за поръчки позволява създаването и управлението на поръчки с продукти от складовете. Всяка поръчка е свързана с клиент и склад, и може да съдържа множество продукти с техните количества и цени.

## Структура

### Order Entity
- **description** - Описание на поръчката
- **client** - Клиент (задължително)
- **warehouse** - Склад (задължително)
- **orderDate** - Дата на поръчката (задължително)
- **deliveryDate** - Дата на доставката (опционално)
- **items** - Колекция от продукти в поръчката

### OrderItem Entity
- **order** - Връзка към поръчката
- **product** - Продукт (задължително)
- **warehouseStock** - Склад и продукт (задължително)
- **quantity** - Количество за поръчка (задължително)
- **availableQuantity** - Налично количество в склада
- **unitPrice** - Единична цена (задължително)
- **totalPrice** - Обща цена (изчислява се автоматично)

## Функционалности

### Създаване на поръчка
1. Избиране на клиент
2. Избиране на склад
3. Задаване на дата на поръчка
4. Задаване на дата на доставка (опционално)
5. Добавяне на описание (опционално)

### Добавяне на продукти
1. Избиране на продукт
2. Избиране на склад и продукт (WarehouseStock)
3. Задаване на количество
4. Задаване на единична цена
5. Автоматично изчисляване на общата цена

### Търсене и филтриране
- По клиент
- По склад
- По дата на поръчка
- По дата на доставка

## API Endpoints

### Order
- `GET /order` - Списък с поръчки
- `POST /order/create` - Създаване на поръчка
- `GET /order/{id}/edit` - Редактиране на поръчка
- `POST /order/deletes` - Изтриване на поръчки

### OrderItem
- `GET /order-item` - Списък с продукти в поръчките
- `POST /order-item/create` - Добавяне на продукт
- `GET /order-item/{id}/edit` - Редактиране на продукт
- `POST /order-item/deletes` - Изтриване на продукти

## Връзки с други модули

- **Client** - Всяка поръчка е свързана с клиент
- **Warehouse** - Всяка поръчка е свързана със склад
- **Product** - Продуктите в поръчката
- **WarehouseStock** - Наличностите в складовете
- **User** - Създател на поръчката

## Бизнес логика

### Валидации
- Количеството за поръчка не може да надвишава наличното в склада
- Всички задължителни полета трябва да са попълнени
- Цените трябва да са положителни числа

### Автоматични изчисления
- Общата цена се изчислява автоматично (количество × единична цена)
- Наличното количество се взима от WarehouseStock

## Използване

### В Twig шаблони
```twig
{# Списък с поръчки #}
{{ path('order_list') }}

{# Създаване на поръчка #}
{{ path('order_create') }}

{# Редактиране на поръчка #}
{{ path('order_edit', {'id': order.id}) }}

{# Продукти в поръчка #}
{{ path('order_item_list') }}
```

### В PHP кода
```php
// Създаване на поръчка
$order = new Order();
$order->setClient($client);
$order->setWarehouse($warehouse);
$order->setOrderDate(new \DateTimeImmutable());

// Добавяне на продукт
$orderItem = $this->orderService->addProductToOrder(
    $order, 
    $warehouseStock, 
    10.0, 
    25.50
);

// Изчисляване на обща сума
$total = $this->orderService->calculateOrderTotal($order);
```
